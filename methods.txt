## ─────────────────────────────────────────────────────────────────────────────
## INVALID COMBINATIONS — pipeline will stop with an error if these are used
## ─────────────────────────────────────────────────────────────────────────────
##
##  CLR   + Bray       → CLR produces negative values; Bray-Curtis requires ≥ 0
##                        Fix: use CLR + Euclidean  OR  TSS/Hellinger + Bray
##
##  Zscore + Bray       → Zscore produces negative values; same issue as CLR
##                        Fix: use Zscore + Euclidean  OR  TSS/Hellinger + Bray
##
##  MinMax + Count      → MinMax is per-sample scaling designed for log10 data
##                        Fix: use TSS | Hellinger | CLR | Rarefaction for Count
##
##  MinMax + Frequency  → Same issue; MinMax is for log10 only
##                        Fix: use None | Hellinger | Zscore for Frequency
##
##  TSS    + Euclidean  → TSS does not centre data; Euclidean distances inflate
##                        Fix: use CLR + Euclidean for count data
##
##  Phylo distance (UniFrac/MPD/MNTD/…) + PhyloTree = None
##                      → Phylo metrics require a reference tree
##                        Fix: set PhyloTree = yourfile.nwk
##
##  PhyloTree = <anything that is not None or *.nwk>
##                      → Will be treated as None with a warning
##                        Fix: set PhyloTree = None or PhyloTree = BacTree.nwk
##
## ─────────────────────────────────────────────────────────────────────────────
